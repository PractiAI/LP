התקנה והיכרות בסיסית

מתקינים את קלוד למחשב, פותחים את לשונית Code, מחברים אותה לתיקיית העבודה ומנהלים שיחה ראשונה.

מה עושיםאיך מתחיליםהפרומפטבדיקת הצלחהנתקעת?

מה אנחנו עושים עכשיו?

נתקין את אפליקציית קלוד למחשב, נפתח בה את סביבת קלוד קוד, ונחבר אותה לתיקיית עבודה מקומית.
בתיקייה הזו ייבנה בהדרגה הסוכן האישי שלכם.

ארבעה מושגים שכדאי להכיר

  • תיקייה: המקום במחשב שבו קלוד עובד. הוא רואה רק את מה שנמצא בתיקייה שבחרתם.
  • מודל: "המוח" שמפעיל את הסוכן. בוחרים אותו בבורר המודלים שבשורה שמתחת לתיבת הכתיבה. לסדנה מתאים מודל ברירת המחדל.
  • הרשאות: קובעות מה קלוד רשאי לעשות בלי לשאול. Manual שואל לפני כל עריכה ופקודה. Accept edits מאשר עריכות קבצים מעצמו. Plan רק מתכנן ומציע, בלי לשנות קבצים.
  • סשן: שיחת עבודה אחת. סשן חדש מתחיל "נקי", ולכן בהמשך נלמד לשמור את מה שחשוב בקבצים.

למה זה שימושי?

בצ׳אט רגיל, קלוד עונה לכם. בקלוד קוד, הוא יכול גם לקרוא קבצים בתיקייה, ליצור מסמכים, לבנות כלים קטנים ולבצע תהליכים שלמים. ההבדל הזה הוא ההבדל בין שיחה לבין סוכן.

איך מתחילים?

  1. היכנסו לכתובת claude.ai/download, הורידו את הגרסה למחשב שלכם (ווינדוס או מק) והתקינו.
  2. פתחו את האפליקציה והתחברו לחשבון קלוד שלכם. לעבודה בקלוד קוד נדרש מנוי בתשלום: Pro, Max, Ultra, Team או Enterprise.
  3. בראש סרגל הצד לחצו על הלשונית Code.
  4. הורידו את חבילת הפתיחה מעמוד חומרי ההורדה, חלצו אותה ושמרו את התיקייה במקום נוח, למשל בשולחן העבודה.
  5. בשורה שמתחת לתיבת הכתיבה בחרו את הסביבה המקומית (Local), ואז Open folder… ובחרו את תיקיית העבודה שחילצתם.
  6. בדקו את מצב ההרשאות בשורה שמתחת לתיבת הכתיבה. בתחילת הדרך מומלץ להשאיר את ברירת המחדל (Manual), שבה קלוד מבקש אישור לפני כל שינוי.
  7. שלחו את הפרומפט הראשון שמופיע למטה.

מה מבקשים מקלוד?

הפרומפט המרכזי של התרגיל. מספיק כדי להשלים את השלב.

מה אמור לקרות?

קלוד מסביר בפשטות מה הוא יכול לעשות, מציג את רשימת הקבצים שבתיקייה ולא משנה דבר. אם הוא מבקש הרשאה לקרוא קבצים, זה תקין: אשרו.

איך יודעים שהצלחנו?

ההתקדמות נשמרת בדפדפן הזה בלבד.

נתקעת?

מופיעה הודעה שצריך לשדרג את החשבון

לשונית Code דורשת מנוי בתשלום (Pro, Max, Ultra, Team או Enterprise). אם אין לכם מנוי, הצטרפו לעמית לצפייה והמשיכו עם מסלול הדוגמה כשתוכלו.

לא מוצאים איך לבחור תיקייה

בשורה שמתחת לתיבת הכתיבה לחצו על בורר הסביבה, בחרו את האפשרות שתחת Local, ואז לחצו על בורר התיקייה ובחרו Open folder…. שמות הכפתורים עשויים להשתנות מעט בין גרסאות.

קלוד מבקש אישור על כל פעולה

זו התנהגות תקינה במצב Manual. קראו מה הוא מבקש לעשות ואשרו. בהמשך הסדנה נשקול לעבור למצב Accept edits.

האם צריך להתקין גיט או Node.js?

לא. אפליקציית קלוד למחשב כוללת את קלוד קוד, ואין צורך בכלי פיתוח נוספים לסדנה הזו.

לא מצאתם תשובה? לעמוד העזרה המלא.

רוצה להעמיק?

נסו לבקש מקלוד לעבוד במצב Plan, ושאלו אותו: "איך היית מארגן את התיקייה הזו לעבודה שוטפת?". שימו לב שבמצב הזה הוא מציע ואינו משנה קבצים.
